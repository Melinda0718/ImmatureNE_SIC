# Data not included in this repository

The patient-level dataset of this study is **not distributed with the code**.

The de-identified data (Day 1 / Day 3 / Day 7 clinical and flow-cytometry variables for
99 patients with sepsis, plus 17 healthy controls) are available from the corresponding
author on reasonable request, subject to institutional approval:

- Xiaojing Wu — 36410257@qq.com
- Yingzi Huang — yz_huang@126.com

`DATA_DICTIONARY.md` in this folder documents every variable name, unit and coding used by
the scripts in `code/`, so the analysis can be reproduced once the data are obtained.

Please cite the article when using the code:
*Circulating CD10⁻ Neutrophil Percentage as a Novel Biomarker for Sepsis-Induced Coagulopathy
Diagnosis: A Prospective Cohort Study.*
